Подробное описание

Главный класс, представляющий абстрактную Машину Тьюринга.

Связывает воедино бесконечную ленту (Tape) и набор правил переходов (RuleSet), управляет состоянием машины и выполняет алгоритм.

◆ step()

bool TuringMachine::step ( )

Выполняет один такт (шаг) работы машины. Считывает символ, находит правило, записывает новый символ, сдвигает головку и меняет состояние.

Возвращает
true, если шаг успешно выполнен. false, если машина остановилась (правило не найдено).
