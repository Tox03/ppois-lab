# Лабораторные работы по дисциплине ППОИС

Репозиторий для выполнения лабораторных работ по курсу «Проектирование программного обеспечения интеллектуальных систем».

---

## Структура репозитория

* **[`lab1/`](lab1/)** — **Лабораторная работа №1. Основы ООП: разработка класса**
  * Реализация двух абстрактных машин:
    1. **Машина Тьюринга** (вариант 1.8.2)
    2. **Нормальные алгорифмы Маркова** (вариант 1.8.3)
  * Консольный интерфейс (меню и CLI с флагом `-log`).
  * Модульные unit-тесты (GoogleTest, покрытие >90%).
  * Документация классов Doxygen.
* **`lab2/`** — Лабораторная работа №2 *(в разработке)*
* **`lab3/`** — Лабораторная работа №3 *(в разработке)*
* **[`lab4/`](lab4/)** — **Лабораторная работа №4. Обобщённое программирование: сортировка и контейнеры**
  * Реализация алгоритмов сортировки (Вариант 4):
    1. **Gnome sort** (Гномья сортировка) с поддержкой компараторов, итераторов, `std::vector`, C-массивов и симметричной сортировкой по возрастанию/убыванию.
    2. **Pigeonhole sort** (Голубиная сортировка) с поддержкой целочисленных ключей и пользовательских объектов через key extractor.
    3. Пользовательский класс `Student` для демонстрации сортировки объектов.
  * Реализация обобщённого контейнера (Вариант 4):
    * **Ориентированный граф на основе матрицы инцидентности** (`DirectedIncidenceMatrixGraph<T>`).
    * Полное сокрытие внутреннего представления.
    * Двунаправленные и обратные итераторы: вершинные, рёберные, инцидентные и смежности.
    * Симметричные операции: добавление/удаление, проверка наличия, очистка/заполнение, степени вершин и рёбер, сравнение графов.
  * Консольный интерфейс: интерактивное меню и автоматический демонстрационный режим (`--demo`).
  * Модульные unit-тесты (GoogleTest, 42 теста, 100% pass, покрытие >90%).

## Быстрый старт (Лабораторная №1)

Подробное описание архитектуры, сборки и запуска находится в файле **[lab1/README.md](lab1/README.md)**.

### Сборка через CMake:
```powershell
cd lab1
cmake -B build -S .
cmake --build build --config Release
```

### Запуск тестов:
```powershell
./lab1/build/Release/AllTests.exe
```

### Запуск программы:
```powershell
# Интерактивное меню:
./lab1/build/Release/ppois-lab1.exe

# Запуск Машины Тьюринга из файла с логированием:
./lab1/build/Release/ppois-lab1.exe turing lab1/examples/turing_example.txt -log

# Запуск Алгорифмов Маркова из файла с логированием:
./lab1/build/Release/ppois-lab1.exe markov lab1/examples/markov_example.txt -log
```
