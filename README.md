# Лабораторные работы по дисциплине ППОИС

Репозиторий для выполнения лабораторных работ по курсу «Проектирование программного обеспечения интеллектуальных систем».

---

## Структура репозитория

* **[`lab1/`](lab1/)** — **Лабораторная работа №1. Основы ООП: разработка класса**
  * Реализация двух абстрактных машин:
    1. **Машина Тьюринга** (вариант 1.8.2)
    2. **Нормальные алгорифмы Маркова** (вариант 1.8.3)
  * Консольный интерфейс (меню и CLI с флагом `-log`).
  * Модульные unit-тесты (GoogleTest, покрытие >90%).
  * Документация классов Doxygen.
* **[`lab2/`](lab2/)** — **Лабораторная работа №2. Крупный ООП-проект: Завод по изготовлению автомобильных деталей**
  * Объектная модель машиностроительного завода (77 классов, 328 полей, 204 метода, 103 ассоциации, 14 исключений).
  * Строгая модульность: 1 класс на 1 файл.
  * Модульные тесты (`unittest`, 72 теста, покрытие кода 98%).
  * Интерактивное консольное меню, сдача заказов, подтверждение доставки клиентом, управление складом и оборудованием.
* **[`lab3/`](lab3/)** — **Лабораторная работа №3. Крупный ООП-проект: Модель социальной сети**
  * Объектно-ориентированная модель платформы социальной сети (60+ классов, 16 исключений).
  * Подсистемы: профили, чаты и звонки, посты и истории, модерация, монетизация и реклама, безопасность.
  * Строгая модульность: 1 класс на 1 файл, соответствие PEP 8 (flake8).
  * Модульные тесты (`unittest`, 35 тестов, покрытие кода >90%).
* **[`lab4/`](lab4/)** — **Лабораторная работа №4. Обобщённое программирование: сортировка и контейнеры (Вариант 4)**
  * **Задание 1**: Обобщённые алгоритмы сортировки:
    1. **Gnome sort** (Гномья сортировка)
    2. **Pigeonhole sort** (Голубиная сортировка)
    3. Пользовательский класс `Student` для демонстрации сортировки.
  * **Задание 2**: Шаблонный контейнер `DirectedIncidenceMatrixGraph<T>` — **Ориентированный граф (матрица инцидентности)**:
    * Полная инкапсуляция матрицы инцидентности.
    * 4 пары двунаправленных итераторов (вершины, рёбра, инцидентные рёбра, смежные вершины) с const и reverse модификациями.
    * Строгая модульность: 1 класс на отдельный `.h` и `.cpp` файл.
  * Модульные unit-тесты (GoogleTest, 47 тестов, 100% прохождение).
  * Интерактивное консольное меню и режим `--demo`.

## Быстрый старт (Лабораторная №1)

Подробное описание архитектуры, сборки и запуска находится в файле **[lab1/README.md](lab1/README.md)**.

### Сборка через CMake:
```powershell
cd lab1
cmake -B build -S .
cmake --build build --config Release
```

### Запуск тестов:
```powershell
./lab1/build/Release/AllTests.exe
```

### Запуск программы:
```powershell
# Интерактивное меню:
./lab1/build/Release/ppois-lab1.exe

# Запуск Машины Тьюринга из файла с логированием:
./lab1/build/Release/ppois-lab1.exe turing lab1/examples/turing_example.txt -log

# Запуск Алгорифмов Маркова из файла с логированием:
./lab1/build/Release/ppois-lab1.exe markov lab1/examples/markov_example.txt -log
```
